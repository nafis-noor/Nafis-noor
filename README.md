🌙 Nafis Noor

Nafis Noor is an Islamic digital platform being developed to bring useful Islamic tools and learning experiences together in one place.

Status: In development. Features listed below reflect the project vision and may not all be implemented or available yet.

✨ Project Goals

Nafis Noor aims to make it easier for users to access Islamic learning tools through a clear, accessible, multilingual experience.

🧭 Planned and Intended Features

📖 Quran

Quran reading and Surah/Ayah navigation

Translations where available

Recitation audio from supported reciters

Bookmarks and reading progress

Tasme3: recitation practice with passage selection and continuous listening, where supported

🕌 Prayer

Daily prayer times and next-prayer information

Prayer reminders and location/calculation settings where supported

🤲 Dhikr & Du'a

Browse adhkar and duas by category, such as morning, evening, after prayer, sleep, gratitude, and forgiveness

Search and save favorites

Arabic text, translations, and source references where available

Completion tracking and audio where legitimately available

Use verified content and permitted sources; never invent religious text or references

🤖 Noor AI

Islamic-focused question-and-answer assistance

Follow-up conversations

References to Quran and Hadith where available and verified

Clear handling of uncertainty and limitations

🎙️ Quran Teacher AI

Choose a Surah and a passage to practise

Spoken prompts and continuous turn-taking without requiring a manual “Next” tap

Feedback and repetition support where speech recognition can reliably identify the recitation

Arabic-capable teacher voice, separate from Quran recitation audio

📚 Learning

Arabic letters, vocabulary, reading, and conversation practice

Interactive lessons, flashcards, and exercises

Progress tracking where implemented

🌐 Languages & Accessibility

Language selection, with intended support for English, Arabic, Amharic, French, Chinese, and additional languages as available

Dark and light themes

Responsive layouts and readable Arabic typography

Guest access where supported

👤 Accounts & Privacy

Account and sign-in features where implemented

Email verification or password-reset flows where configured

Secure handling of user data and API credentials

Privacy information and clear error states

🛠️ Technology

The project is worked on using Visual Studio Code (VS Code) and modern web-development tools. AI-powered features may use external AI services and APIs.

The exact frameworks, services, and commands depend on the current codebase. Check the project's configuration files (such as package.json) before installing dependencies or running the app. Never expose API keys in client-side code or commit secrets to version control.

🚀 Getting Started

Install Visual Studio Code and Node.js if the project uses a Node.js-based setup.

Open the project folder in VS Code.

Review package.json and the project's setup instructions.

Install dependencies using the package manager specified by the project.

Configure required environment variables using a local .env file, if needed. Do not commit secrets.

Run the development command listed in package.json.

The exact setup commands are intentionally not specified here because they depend on the project's actual framework and scripts.

🔐 Accuracy, Safety & Reliability

Treat Quran text and religious references with care; verify content against trusted sources.

Do not present generated AI responses as definitive religious rulings.

Be transparent when a feature, audio source, or live data connection is unavailable.

Do not display fake data, simulated listening, or nonfunctional controls as real functionality.

Protect personal data and API keys.

🗺️ Roadmap

The project may continue to improve across Quran tools, prayer features, Dhikr & Du'a, AI-assisted learning, voice interaction, accessibility, and language support. Planned work is not a promise of a release date or a claim that a feature is already available.
